# Embedded Data Provenance

Any external dataset, table, catalog, coefficient set or other redistributable scientific material intended for embedding in the shipping one-file artifact should have a machine-readable provenance record before promotion.

Records should conform to `config/governance/ip-provenance.schema.json` and identify source/version, license expression, redistribution/commercial-use permissions, attribution requirements and a checksum when a stable source artifact exists.

A useful scientific source is not automatically redistributable. Unknown redistribution rights fail closed for shipping embedding.
