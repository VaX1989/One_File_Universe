# One File Universe RFCs

RFCs propose durable changes to OFU architecture, governance, interoperability, canonical semantics, or other high-impact contracts.

Read `docs/community/RFC_PROCESS.md` before opening one. Copy `rfcs/TEMPLATE.md`, assign the next available number after maintainer triage, and keep the discussion linked from the RFC.

An RFC is not authority to merge implementation. Accepted RFCs still require normal code review, tests, and integration evidence.
