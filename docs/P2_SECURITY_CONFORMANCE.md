# P2 Security, Conformance and Reproducibility Model

## Typed evidence

P2 evidence has a common versioned envelope: `evidenceSchemaVersion: 1`, `phase: "P2"`, `evidenceKind`, `producer`, `sourceCommit`, and `status`. Defined kinds are `p2-browser-conformance`, `p2-node-oracle`, `p2-benchmark`, `p2-build-manifest`, `p2-reproducible-build`, and `p2-aggregate`.

The aggregate gate selects by declared kind, never by filename. Malformed or untyped JSON in P2 artifacts, non-PASS inputs, missing/unexpected browser targets, duplicate/conflicting target evidence, source-commit disagreement, direct-open drift, canonical-field disagreement and reproducible-build disagreement produce machine-readable failures. Legitimate Node/oracle/build/benchmark records cannot be mistaken for browser evidence.

Every certifying input carries the same exact 40-character source commit. Workflows explicitly checkout the PR head or pushed SHA and verify `git rev-parse HEAD`. Local evidence uses `LOCAL-UNPINNED` and cannot satisfy the aggregate schema.

## Golden Universe Corpus v1

`tests/vectors/golden-universe-corpus-v1.json` is generated by the independent Python oracle. JavaScript requires semantic equality with a fresh oracle run. It contains primitive/integer/Unicode/container vectors, every address segment type, deterministic address-boundary recipes, malformed canonical/address rejection vectors, exact resource-limit declarations, Entity/Universe identity values, deterministic numeric cases and a reproducible 256-query generated corpus with a pinned Kernel Digest. Unknown explicit oracle case kinds fail closed and every explicit case is consumed exactly once.

## Property, metamorphic and fuzz testing

The suite verifies canonical value and canonical-byte round trips, non-canonical alias rejection, map permutation invariance, Unicode normalization invariance, normalized-key collision rejection, shared map-key/value traversal accounting, exact byte/depth/collection/address boundaries, identity/domain/property/address/counter separation and numeric boundaries.

Mutation fuzzing is deterministic: seeds `0x5eed1234` and `0x00c0ffee`, 5,000 mutations per seed. Mutation modes include bit flips, truncation, append and inserted overlong-varint material. A mutated stream either fails or is already canonical and re-encodes byte-identically.

## Cross-runtime contract

Required automated targets are Linux x64 Chromium, Firefox and WebKit; Windows x64 Chromium; and macOS ARM64 WebKit. Each report records browser/version, Playwright, Node, OS platform, architecture, `file:` protocol, canonical pins and three worker digests. Direct execution, Worker-1, reordered Worker-2 and Worker-4 must agree.

Playwright WebKit is WebKit automation evidence, not Safari certification. Real Safari/iOS remains `NOT_VERIFIED` unless directly executed.

## Reproducible build

The exact checkout removes `dist/`, performs a clean build, removes `dist/` again, performs a second clean build, then requires byte-identical HTML SHA-256 and length. Reproducible-build evidence must match the build manifest.

## Performance scope

`tools/p2-benchmark.mjs` measures canonical serialize/decode, SHA-256, HMAC derivation, address creation and independent-oracle corpus work with runtime, iterations, sizes, elapsed time and throughput where meaningful. Performance observations are excluded from Semantic Manifest hashing and identities.

## Security scope and limits

Explicit input/traversal/address bounds reduce parser and resource-amplification risk; this is bounded-behavior evidence, not a proof against every denial-of-service strategy or host-runtime memory policy. P2 relies on SHA-256 collision resistance and standard HMAC behavior. Identity digests are deterministic identifiers, not secrecy guarantees. HMAC unpredictability requires a secret high-entropy key, which P2 does not assume for every user-provided seed.

## P1 inherited portable-save finding

Review reproduced an asymmetry: import enforced the 1 MiB final save-text limit while export did not. The isolated remediation applies the same final UTF-8 byte bound to export and adds a dedicated P1 regression test. Previously importable canonical saves are unchanged.

## Evidence terminology

Use precisely: `CLAIMED`, `DOCUMENTED`, `SOURCE_EXISTS`, `IMPLEMENTED`, `TEST_DEFINED`, `TEST_EXECUTED`, `BROWSER_EXECUTED`, `ORACLE_VERIFIED`, `CROSS_RUNTIME_VERIFIED`, `PASS`, `FAIL`, `PARTIAL`, `ENVIRONMENT_LIMITED`, `NOT_EXECUTABLE_IN_ENVIRONMENT`, `NOT_VERIFIED`, `PRODUCTION_VALIDATED`.
