# PROD-W1-PRODUCT-DEPTH — Founder-visible depth without authority inflation

This lane increases perceptual depth and product legibility by consuming signals that R6 already governs.

## What changes

- HUMAN aerial perspective is derived from the existing scientific/model state, causal presentation consequences, terrain presentation palette and HUMAN place grammar.
- The existing bounded far-field gains deterministic haze/contrast cues and a physical near/mid/far metre composition using the same 256-vertex ceiling; no world or object scale is inflated.
- Babylon scene fog is enabled only while HUMAN owns the presentation and is restored exactly when HUMAN is left.
- Existing local presentation materials gain bounded specular/patina cues.
- Phone portrait scale labels wrap instead of being forcibly ellipsized, while orientation, product identity, status and command controls remain geometrically non-overlapping.
- Progressive macro visual evidence waits for the renderer's committed residency signature before selecting/capturing landmarks.

## What does not change

No canonical identity, P2/P4 history, model/scientific state, geometry authority, selection authority, camera authority, physical object position or world-space scale is changed.

The new depth profile is explicitly `PRESENTATION_ONLY`. It does not assert:
- actual weather;
- calibrated atmospheric spectrum;
- ocean/coast geometry;
- exact mineralogy;
- specific crater/ridge/basin/fracture placement;
- measured surface exposure age.

## Product-depth evidence

The profile exposes a multidimensional QOBS descriptor spanning silhouette/topography, horizon, roughness, sky regime, material family, object clustering, scale distribution, palette, causal fingerprint and perceptual topology. Palette-only change is never treated as sufficient product diversity.

Existing mandatory browser journeys are strengthened rather than bypassed:
- HUMAN renderer test proves scale stability and exact presentation restore;
- multi-world generalization requires non-palette depth differences across real materialized worlds, runs those live descriptors through the canonical QOBS diversity scorer, and replays the first evicted world to recover the exact prior product-depth descriptor;
- visual evidence waits for committed macro residency;
- accessibility/mobile checks portrait readability;
- the full Spatial Continuum convergence runner still owns continuity, browser, direct-file/offline and resource regression.

## Resource boundary

No new scene, camera, mesh, texture, cache, worker or unbounded resident collection is introduced. Depth uses the existing HUMAN far-field/materials and one scene fog state, with explicit baseline restore.
