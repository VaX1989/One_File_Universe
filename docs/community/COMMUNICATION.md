# Communication and Decision Memory

OFU should be easy to discuss and hard to govern accidentally from private chat.

## Rule

**Conversation can happen anywhere. Durable project decisions must end up in the repository.**

Issues are appropriate for concrete defects/tasks. RFCs are appropriate for durable design proposals. Pull requests are appropriate for reviewing exact changes. ADRs record accepted long-lived architecture. Governance records define authority.

## Future community spaces

GitHub Discussions is the preferred target for broad Q&A, ideas, science discussion, rendering/performance discussion, contributor help, and show-and-tell once enabled. Real-time chat may be added later for social coordination, but it must not become the only location of architectural decisions.

## Language

English remains the normative project language as defined by the Constitution so contributors can share one searchable technical record. Community translations are welcome when clearly non-normative.
