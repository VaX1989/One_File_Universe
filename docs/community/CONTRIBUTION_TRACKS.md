# Contribution Tracks

OFU deliberately supports different kinds of expertise.

## Documentation and onboarding

Good for first contributions. Improve clarity, examples, diagrams, terminology, navigation, accessibility of documentation, or contributor experience. Documentation that changes normative meaning is not a low-risk typo.

## Testing and falsification

Add regressions, adversarial fixtures, browser witnesses, performance probes, reproducibility checks, scientific oracles, and failure-path tests. Evidence code must be as honest as production code.

## Product, UX, accessibility, and audio

Improve direct manipulation, discovery, responsive behavior, keyboard/touch support, assistive semantics, feedback, and systemic audio while respecting central input/camera/selection authority.

## Rendering and performance

Work on WebGL2/WebGPU, shaders, batching, culling, quality, context recovery, materialization, scheduling, memory/resource bounds, and measurement. Measured evidence and modeled estimates must remain distinct.

## Runtime and build

Work on deterministic composition, registries, streaming, workers, caching, persistence plumbing, packaging, artifact reachability, reproducibility, and developer tooling.

## Simulation and gameplay

Work on causal state, intervention, temporal behavior, economy, ecology, individuals, and other model-derived systems without bypassing canonical event/history authority.

## Science and data

Contribute models, validations, datasets, literature-backed constraints, uncertainty treatments, negative/unknown states, and provenance. Read `docs/community/SCIENCE_CONTRIBUTIONS.md` first.

## Core architecture

Identity, address semantics, determinism, time/history, persistence formats, authority classes, and cross-scale contracts have a high blast radius. These normally require an RFC and experienced review.

## Research frontier

Research can explore mechanisms not ready for shipping. Research-only work must remain explicitly non-canonical until a separate promotion decision supplies the required evidence and authority review.
