# The OFU Way

This is the short cultural map of One File Universe. The Constitution is normative; this document explains the habits that should make its principles obvious in everyday work.

1. **One universe, one shipping artifact.** Source is modular; the strict product is one self-contained HTML file.
2. **Identity survives scale.** Zooming/refining must not silently replace one reality with unrelated content.
3. **Unknown is a valid answer.** Never invent truth merely to fill a gap.
4. **Presentation does not own reality.** A beautiful renderer cannot manufacture canonical or scientific facts.
5. **Canonicality precedes acceleration.** GPU, worker, cache, frame timing, and device differences must not rewrite canonical meaning.
6. **Materialize what is needed, not the universe.** The theoretical world may be enormous; active resources stay bounded.
7. **Causes should have consequences.** Prefer coherent causal derivation to independent decorative randomness.
8. **Every durable truth has provenance.** Identity, authority, source model, uncertainty, history, and evidence should be inspectable.
9. **Evidence before claims.** Code existing is not proof that the product uses it; a test existing is not proof that it passed.
10. **Fail closed on authority.** Ambiguity must not silently grant stronger semantics.
11. **Research may be adventurous; promotion must be conservative.** A frontier model can be valuable without becoming product truth.
12. **Complexity belongs behind contracts.** A contributor should understand their interface and invariants without loading the whole project into their head.
13. **Open discussion; durable decisions.** Important decisions end up in the repository.
14. **Commercial money cannot purchase scientific truth.** Licensing and sponsorship never bypass evidence or authority.
15. **Leave the project easier to understand.** Good contributions improve not only capability but also the next contributor's ability to reason about it.
