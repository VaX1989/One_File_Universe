> **Status: NON-CANONICAL BRAND EXPLORATION.** These files are design studies and review assets. Nothing in this directory is a shipping requirement unless the founder explicitly promotes it in a later integration step.

This directory is the isolated collection point for the visual identity work of **One File Universe**. It intentionally does not touch active V2 convergence, cinematic, runtime, renderer, release, workflow or governance files.

## Current creative thesis

The current direction is built around:

- **one reality across every scale**;
- **boundary × depth × continuity**;
- a registration / section mark rather than a planet, orbit, atom, infinity sign, AI spark, or generic sci-fi glyph;
- a possible `O / F / U` monogram where the outer frame suggests **O**, the registration axis suggests **F**, and a doubled lower contour suggests **U**;
- sparse, near-monochrome composition with restrained mineral/biological accents;
- the same visual reference point surviving changes from cosmic to planetary, human, cellular and material regimes.

The name remains **ONE FILE UNIVERSE**. `One reality. Every scale.` is a brand theorem / strategic line, not a scientific claim.
