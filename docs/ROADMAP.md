# One File Universe Roadmap

**Roadmap style:** evidence-gated, not calendar-gated.

## Status

- **P0 — Constitution & Foundation:** COMPLETE.
- **P1 — Constitutional Prototype:** EXIT GATE SATISFIED on executed evidence; promotion to `main` is the remaining release-control action.
- **P2 — Deterministic Kernel:** NOT STARTED. It must branch only from verified post-P1 `main` after the multiscale architecture ratification interlock.
- **P3 — Universe Skeleton:** BLOCKED by P2.

## P1 — Constitutional Prototype

P1 falsified and then hardened the single-file architecture. The final gate includes deterministic modular-to-one-file build, Strict direct-open, zero application-owned runtime network/local-file dependencies, internal component integrity, Worker transferables and 1/2/4 order independence, bounded Worker failure behavior, embedded WASM experiment, non-authoritative rendering, bounded portable save semantics, pinned corpus result, byte-reproducible builds and a machine-enforced five-target evidence aggregate.

Final certified code evidence is recorded in `docs/evidence/P1_VERIFICATION.md`. P1 does not certify real Safari/iOS/mobile, record-scale compression, production cosmology, Rust/WASM or Zig/WASM.

## P2 — Deterministic Kernel

### Objective
Create the portable authority oracle for all future generators.

### Required pre-implementation interlock
Ratify only the multiscale architectural semantics that affect long-lived identity, addressing, query context, model regimes, observation/materialization, scale bridges, evidence/fidelity and universe genesis/law-profile identity. Do not implement multiscale gameplay or production science during the interlock.

### Deliverables
- formally specified canonical value model and bounded canonical encoding;
- canonical entity identity and address schema separated from Query Context and Model Regime;
- explicit Universe Identity schema;
- semantic Generator Manifest separated from Implementation and Conformance manifests;
- selected domain-separated derivation construction;
- hardened SHA-256 oracle evidence;
- domain-driven deterministic numeric primitives;
- Golden Universe Corpus v1;
- independent Python protocol oracle;
- deterministic property/metamorphic/fuzz campaigns;
- concurrency/order-independence tests;
- cross-engine/OS conformance using the aggregate evidence gate;
- reproducibility, performance, security and compatibility reports.

### Exit gate
The same normative Golden Universe Corpus v1 digest must be produced by the primary implementation and independent oracle and across the declared executed runtime matrix. All valid review findings must be resolved and CI must be green on the exact merged head. P2 must not implement production astronomy.

## P3 — Universe Skeleton

P3 may begin only after P2 closes. Its purpose remains sparse random access across astronomical scales without materializing the universe. Production galaxy/star/planet distributions belong there or later, not in P2.

## Later phases

P4 Temporal Kernel & Mutable World; P5 Planetology/Terrain/Climate; P6 Biosphere/Evolution; P7 Civilization/Culture/Economy; P8 History/Late Materialization; P9 Exploration/Gameplay; P10 Rendering/Audio/Product Maturity; P11 Certification Candidate; P12 Scale Campaign.

## Roadmap rule

A later phase may prototype earlier only to reduce risk; it may not silently override an upstream constitutional or protocol contract. Discoveries that invalidate an accepted ADR require explicit ADR and compatibility treatment before dependent stable generators proceed.
