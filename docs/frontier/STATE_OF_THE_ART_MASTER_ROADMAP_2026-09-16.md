# 1. Post-W0 strategic answer

The question is no longer:

> What must OFU do to achieve Continuous Reality?

R6/W0 M0 answered that question within its declared evidence gate.

The current question is:

> What should OFU build now that Continuous Reality is a certified part of active R6?

The answer is a three-part frontier:

1. **Product depth without reopening M0** — increase perceived cosmic scale, world individuality, HUMAN richness, visual polish, orientation and adaptive quality while preserving the W0 substrate.
2. **Scientific observability as infrastructure** — make scientific fingerprint, provenance, typed causal ancestry, uncertainty and authority-aware inspection first-class state/projections, not explanatory prose pretending to be authority.
3. **Explorer memory as infrastructure** — establish exact saved places, observations, snapshots, routes and deterministic return so future time, search, compare, guided journeys and notebook-like workflows have a durable address model.

Quality Observatory becomes a continuous governance layer across all three, not a late feature milestone.

# 6. Generation criterion — remain in R6 by default

M0 completion does **not** itself justify R7.

Continue as `R6/W1`, `R6/W2`, ... while work is additive or versioned within the existing R6 Continuous Reality substrate.

A new generation becomes justified only when at least one change requires a generation-level compatibility boundary, for example:

- replacing canonical address/identity semantics rather than extending them;
- replacing the authoritative camera/selection/scale-travel contract;
- changing the single-file/offline runtime contract or baseline rendering architecture incompatibly;
- replacing P4 persistence/event semantics rather than adapting to them;
- introducing an incompatible world-state authority model that cannot coexist through versioned adapters;
- requiring a deliberately incompatible artifact/runtime profile with a migration story.

Visual richness, fingerprint/provenance, Atlas, search, compare, time projections, instruments, adaptive quality and audio do not automatically require R7.

Adopt this dependency spine:

- universe identity and canonical spatial address;

This is prerequisite infrastructure for time, search result collections, compare sessions, guided journeys, a scientific notebook and exact return to `where + what I observed`.

# 14. Anti-stop agentic control contract

Future execution agents must treat unfinished work as an execution state, not a reporting endpoint:

```text
UNMET_GATE -> WORK_ITEM
WORK_ITEM -> NEXT_ACTION
FAILED_ACTION -> CLASSIFY -> REPAIR_OR_ROUTE -> CONTINUE
```

Anti-loop rule:

If the same failure fingerprint repeats without measurable progress, the agent must stop repeating the same strategy, invalidate or weaken the current hypothesis, increase instrumentation, minimize the reproducer, choose an alternate repair strategy, and record the transition.

Large missions should persist at least:

```text
failure_fingerprint
failure_count
current_hypothesis
last_action
next_action
alternate_strategy
evidence_refs
```
