# Wave A world convergence

This is a development candidate, not v1.0.0 and not a main promotion. Exact
source commit, tree, artifact bytes/hashes and browser results are recorded in
the accompanying workflow evidence, not guessed from a dirty worktree.

## Inputs and ownership

`wave-a-inputs.json` records the original frozen base and all six live-verified
lane heads/trees. Six normal merges preserve every input's ancestry. The
existing definitive branch's workflow-only descendant was preserved as well.
No historical research branch was substituted for a Wave A input.

The production component loader deterministically seals every code, style,
provider, regime and bootstrap component. The existing provider registry
rejects duplicate IDs and ownership claims. The composed world-scene provider
is registered, bound and invoked by the foreground renderer; it is not an
unused catalogue entry. The primary microscopic descriptor now describes the
source-bound material/microstructure/molecular/atomic graph. The older
biological tissue/cell graph remains explicitly available as legacy semantics,
not as an infinite geometric camera-zoom claim.

## Executable experience

Open the production single-file HTML. Select a real P3 galaxy, region,
neighborhood, system and body. The bounded survey operates relative to the
selected system, not a hidden showcase world. A living result can be approached,
selected anywhere on its supported surface, explored at regional/local/human
scales, and inspected at the exact locations of its terrain-backed settlements.
Actual local rocks, liquids, ice, organisms and manufactured material own their
microscopic contexts. Backtracking restores the original source object and
microdegree location. Canonical moons have independent body identities; their
reduced-order forcing/composition assumptions are disclosed. Gas giants do not
acquire a fictional solid surface.

The common causal path is canonical identity/astronomy, model astronomy,
planetary formation/composition/interior/environment, local climate/hydrology,
evolved ecology/intelligent lineage, geography/resources, civilization/history,
local materials and microscopic representations. The renderer samples that
same environment and coordinate frame. It does not invent a second terrain,
seed independent cities, or show organisms where local eligibility fails.

History controls are bounded, deterministic **model projections**. They do not
commit P4 events. P4 remains the admission authority for canonical history.
Model biospheres are not canonical P6 evidence. No canonical kernel is changed.

## Material repairs and regressions

- The exploration tests' manual loaders omitted the new environment dependency.
  They now load the actual causal world prerequisites.
- Regional P3 calls used product-key names in the canonical sector API. The
  mapping now belongs to the address-space owner rather than a monkeypatch.
- A traversal `else` bound to the wrong conditional and failed to index returned
  single nodes. Transactional navigation, bounded history and exact return are
  covered by the integrated journey tests.
- Evolved-life cache keys omitted generation and occupancy inputs. They now bind
  all generation inputs; ineligible local environments return zero populations.
- Sea level was independent of the generated terrain range, flooding every
  sampled settlement site. A bounded equal-area terrain quantile calibration
  restores the modeled land/water relationship. Local liquid/ice/precipitation
  and material state respect actual inventory and phase eligibility.
- Compatibility volatile composition double-counted the causal fractions.
  Silicate, metal and volatile fractions now conserve one million ppm.
- Civilization was disconnected from actual evolved intelligence and local
  land/resources. Settlement regions now derive from the same location frame
  used by geology, hydrology, ecology and rendering. Route lengths use modeled
  geodesic endpoints; schematic routes are not asserted to be literal roads.
- Candidate pagination skipped remaining planets in a system. Its cursor now
  includes the orbit slot; repeated one-world pages equal one larger page.
- Material-source adapters reject invented local objects and unsupported
  settlement aggregates. Unknown chemistry stays unresolved rather than
  fabricating atoms. A scene with zero represented entities still consumes one
  operation; the metering regression covers all four micro regimes.
- The history slider rounded the initial epoch because its step disagreed with
  the integer model contract. Every modeled epoch 0 through 60 is selectable.
- Shader initialization cleans up partial allocations. Rendering errors are
  detected rather than silently counted as successful frames. A failed backend
  is disposed and uses a bounded CPU fallback; fallback is not GPU evidence.

### Why one historical oracle changed

The discovery oracle previously asserted exact positive-world IDs from the
pre-convergence placeholder environment/civilization pipeline. Their positivity
is not a frozen canonical fact. The replacement is stronger: every discovered
ID must resolve to the actual P3 input; world regeneration is stable; living
results require real evolved intelligence and terrain-backed settlements;
negative worlds remain negative; arbitrary small pagination must produce the
same ordered results without duplicates or skipped orbit slots. Canonical P6
and selection authority remain independently checked. No red scientific oracle
was relaxed to manufacture life or civilization.

## Bounds

Discovery is paginated, at most 128 system queries and 12 modeled worlds per
interactive survey page; at most 24 pages per click, yielding between pages.
Navigation history is 64 frames, discovery cache 12, world cache 16, body cache
8, candidate cache 32 and traversal index 256. Local surface windows use 192
samples. Globe textures use 96 by 48 samples and an LRU of two textures. The
renderer owns two GPU programs, one buffer and one bounded texture. Material
micro views use at most 64 structural features, 24 chemical units and 96 atoms;
transition history and representation caches are separately bounded.

## Evidence and scope

`tools/run-wave-a-development.mjs` runs every non-browser v1 development test.
FAST_LOCAL and INTEGRATION conformance tiers also validate the composed
registry and prior extension contracts. The browser gate uses actual visible
controls, non-bootstrap discovery, arbitrary coordinates, living and sterile
branches, contextual micro return, history and a touch-sized viewport. Browser
screenshots are rendered product evidence, not generated illustrations.

FILE_DIRECT evidence requires opening the built file URL with network disabled
and WebGL2 enabled. LOCAL_CONTENT is a separately labelled diagnostic mode for
managed browsers that disallow file URLs; it never counts as direct-open or
GPU verification. Physical Safari/iOS/Android, driver VRAM and scientific model
validation are not inferred from a headless browser. These are reduced-order,
model-derived worlds with schematic settlement aggregates and representative
microstructures, not measured worlds or atomically exhaustive simulations.

Only a green exact-source double build plus registered development/integration
and direct-open browser evidence establishes `WAVE_A_LIVING_UNIVERSE_COMPLETE`.
The resulting source may then fast-forward the definitive v1 integration line.
It must not merge to main or declare v1.0.0.
