## Composed relief defects

Fresh exact-source Wave IV screenshots showed a sawtooth ridge in Regional
terrain. The composed relief addon had reintroduced an absolute-value ridge
cusp even though the base continuity field already provided a differentiable
profile. The addon now uses that same smooth ridge profile. Its seed and phase
locations are preserved; no geological or physical elevation claim is added.

A separate cache-eviction reproduction on the canonical preview planet found
that returning to the same tile changed a vertex height by 1626.9448852539062 m.
The addon remembered historical tile IDs in an unbounded Set. After eviction,
a regenerated object with the same ID was incorrectly treated as transformed.
Weak membership by mesh object now transforms each fresh object once, permits
collection of evicted history, and avoids reapplying relief to warm objects.
