## Numeric policy

Persistent-looking values in the JavaScript prototype use `BigInt` integer/fixed-point arithmetic. Ratios use nearest-ties-to-even division. The grey-atmosphere fourth root uses integer comparison, not `Math.pow`. The rocky radius proxy uses an integer 37th-root approximation inherited from the frozen P5 research lineage. The energy-limited escape equation is evaluated as an exact rational over integer-scaled inputs. The climate, volatile, thermal, water and cross-scale ledgers have exact integer conservation checks.

The independent Python oracle intentionally uses 90-digit `Decimal` and does not import production code. Therefore it is a numerical comparison, not a duplicate implementation. Floating-point/high-precision oracle results are **test evidence only** and have no state authority. A promoted form would need frozen units, bounds, rounding, source constants, golden vectors, cross-runtime witnesses and P4 transition semantics.

4. Thermal reservoir obeys exact input-output accounting and rejects negative next state.
