# One File Universe Name and Trademark Policy

The software license and the project identity are separate matters. GPL-3.0-only grants copyright permissions; it does not grant trademark rights.

This file establishes an interim community policy for the names **One File Universe**, **OFU**, project logos, and future certification marks. It does not assert that any particular mark is registered, and it does not replace jurisdiction-specific legal advice.

## Uses encouraged without separate permission

You may truthfully refer to the project, link to it, describe compatibility with it, state that software is based on or derived from OFU, discuss or review it, and use the project name in ordinary nominative ways that do not imply endorsement.

Examples:

- `Compatible with One File Universe`
- `A fork of One File Universe`
- `Provider for OFU`
- `Built using One File Universe`

## Uses that require care or permission

Do not present a modified or third-party distribution as the official OFU release, imply project endorsement or certification that has not been granted, or use project branding in a way likely to confuse users about source or governance.

Names such as `Official One File Universe`, `OFU Certified`, or visually confusing official branding may be reserved for project-approved use if and when a formal trademark/certification program is adopted.

## Forks

Forking the software under GPL-3.0-only is allowed. A fork should be clearly distinguishable when its changes could make users believe it is the project-maintained build.

## Future stewardship

A future organization or foundation may hold or administer project marks under the governance model. Any such transfer must not alter the Open Source license of already released code.
